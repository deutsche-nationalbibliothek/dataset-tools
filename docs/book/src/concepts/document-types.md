# Document Types

> [!NOTE]
> The following list of document types is still a work in progress.
> If you need a new type, please create a [GitHub issue] (preferably
> referencing an existing entry from a reference system such as [FaBiO],
> [COAR resource types], or the [DINI publication types]).

## List of document types

- `abstract`
- `bachelor-thesis`
- `blog-post`
- `blurb`
- `conference-object`
- `conference-paper`
- `conference-proceedings`
- `correction`
- `diploma-thesis`
- `doctoral-thesis`
- `journal-article`
- `journal-object`
- `letter-to-the-editor`
- `magister-thesis`
- `master-thesis`
- `musical-notation`
- `none` (default)
- `nonfiction-book`
- `other`
- `policy-paper`
- `preface`
- `preprint-article`
- `retraction-note`
- `review`
- `scientific-article`
- `statistical-report`
- `study-thesis`
- `table-of-contents`
- `textbook`
- `working-paper`
